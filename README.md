# FastChat Notifications

Микросервис уведомлений для мессенджера **FastChat**. Разработан на **FastAPI**, **Beanie** и **MongoDB**. Проверка прав доступа реализована через **JWT** токены, используется асимметричный алгоритм **RS256**, уведомления хранятся в **MongoDB**, для их получения используется **SSE** протокол. Для получения данных из основного приложения и рассылки уведомлений между воркерами используются **Faststream** и **Kafka** в роли брокера сообщений.

## 🚀 Возможности (Use Cases)

- **JWT-аутентификация**:
  - Проверка прав доступа и получение данных пользователя из Access токена
- **Управление уведомлениями**:
  - Получение персональных непрочитанных уведомлений
  - Отметка уведомлений как прочитанных
  - Получение уведомлений в режиме реального времени через SSE

## 🛠️ Используемые технологии

| Технология               | Назначение                                                         |
|--------------------------|--------------------------------------------------------------------|
| **Python 3.14**          | язык разработки                                                    |
| **FastAPI**              | веб-фреймворк (асинхронный, OpenAPI, валидация)                    |
| **Beanie**               | ODM + асинхронная работа с MongoDB                                 |
| **MongoDB**              | основная база данных                                               |

| **uvicorn**              | ASGI-сервер                                                        |
| **pydantic-settings**    | управление переменными окружения                                   |
| **ruff**                 | форматирование и линтинг кода                                      |
| **uv**                   | управления зависимостями                                           |
| **docker**               | запуск и развертывание                                             |

## ✨ Запуск проекта

Необходимо скопировать публичный ключ основного приложения в папку secret_keys:
 ``` bash
mkdir secret_keys
cp ../fastchat-backend/secret_keys/public.pem ./secret_keys/
```

Создание docker-сети:
```bash
docker network create fastchat-net
 ```

Запуск Docker контейнеров
```bash
docker compose up -d
 ```
